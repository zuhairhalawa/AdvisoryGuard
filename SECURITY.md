# Security policy

AdvisoryGuard is an offline, read-only command line tool. It never opens network connections, never
executes content from the files it reads, and never writes to them.

If you find a vulnerability in AdvisoryGuard itself (for example a crafted advisory file that makes the
tool crash, hang, execute code or print misleading output), please report it privately through GitHub's
"Report a vulnerability" button on the repository's Security tab rather than a public issue.

Supported versions: the latest released minor version.
